# Plain-instruction integration review

Reviewed 2026-11-11. SimpleEnglish's condition placement, terminology and
reader-knowledge checks suggest a focused addition to the existing prose pass.
The existing guidance already preserves qualifiers, prerequisites and literal
names; the addition makes the decision point and audience explicit. It does not
adopt fixed length limits or controlled vocabulary.

The [proposed probe](README.md#proposed-plain-instruction-probe) tests those
criteria against a small synthetic setup guide. It has not been run with an
independent agent. It is a design probe, not evidence of improved performance.

[HIGAgentSkills](https://github.com/justinwetch/HIGAgentSkills/tree/2206ff935b4affa9ad249a5399a3e8e29f5f6edd),
reviewed at revision `2206ff935b4affa9ad249a5399a3e8e29f5f6edd`, routes a large
platform reference corpus by topic. Reader First already loads its small,
task-specific references selectively. A separate routing index or mandatory
reference expansion would add complexity without a demonstrated need here. No
HIG content or workflow is incorporated.
